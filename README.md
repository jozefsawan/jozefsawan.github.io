## ✨ Features

- **Bilingual Support** - Toggle between English and French with a single click
- **Dark/Light Mode** - Choose your preferred viewing experience
- **Responsive Design** - Optimized for all devices (mobile, tablet, desktop)
- **Interactive Elements** - Engaging animations and transitions
- **Canvas Background Effects** - Dynamic particle animations
- **Accessibility Focused** - Follows WCAG guidelines for better readability
- **Performance Optimized** - Fast loading times and smooth scrolling
- **Contact Form Integration** - Easy to reach out via the built-in form

## 🎨 Design Philosophy

This portfolio was designed with a focus on modern aesthetics, accessibility, and user experience. The clean, minimalist approach puts the content first while subtle animations and interactive elements create an engaging experience.

The color scheme uses a carefully selected palette that works harmoniously in both dark and light modes, ensuring optimal readability and visual appeal regardless of the user's preference.

## 🧰 Technical Implementation

### Responsive Layout
The portfolio uses a flexible grid system and responsive units to ensure a consistent experience across all device sizes. Media queries are strategically implemented to optimize the layout for different viewport dimensions.

### Interactive Elements
JavaScript is used to create smooth animations, handle user interactions, and manage state (language preference, theme selection). The code is organized for maintainability and performance.

### Background Effects
Canvas-based particle animations create a subtle, engaging background that responds to user scrolling and viewport changes. The effect is optimized for performance with reduced complexity on mobile devices.

### Accessibility
The site follows accessibility best practices including:
- Semantic HTML structure
- Appropriate color contrast
- Keyboard navigation support
- Text spacing for improved readability
- Screen reader compatibility

## 🌐 Languages

The portfolio supports both English and French languages, with a seamless switching mechanism that preserves the user's preference across sessions using localStorage.

## 🔄 Theme Switching

Users can toggle between dark and light modes with a dedicated theme switch in the navigation bar. The preference is saved for future visits.

## 📱 Responsive Behavior

The portfolio adapts to different screen sizes:
- **Mobile**: Streamlined navigation with optimized content layout
- **Tablet**: Enhanced layout with adjusted grid for better content consumption
- **Desktop**: Full experience with all visual elements and optimal spacing

## 🚀 Performance Optimizations

- Efficient CSS with minimal redundancy
- Optimized JavaScript execution
- Responsive image loading
- Reduced animation complexity on mobile devices
- Minimal external dependencies

## 🔧 Setup and Customization

1. Fork this repository
2. Enable GitHub Pages in your repository settings:
   - Go to Settings > Pages
   - Select the main branch as the source
   - Click Save
3. Customize the content in `index_new.html` to showcase your own work and information
4. Update the styling in `styles_new.css` to match your personal brand
5. Deploy to your preferred hosting platform
