# Portfolio Website

A personal portfolio website with a dynamic character animation background inspired by midjourney.com.

## Features

- Responsive design
- Three.js animated background with floating characters
- Modern UI with a clean layout
- Easily customizable

## How to Use

1. Fork this repository
2. Enable GitHub Pages in your repository settings:
   - Go to Settings > Pages
   - Select the main branch as the source
   - Click Save
3. Customize the content in `index.html` to showcase your own work and information
4. Update the styling in the CSS section to match your personal brand

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js for 3D animations
